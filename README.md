# Phase 1

A getter is better because discountedPrice is calculated using the current
base price and discount. 

# Phase 2

The regular constructor allows every property to be customized. Product.onSale
automatically applies a 10% discount, while Product.bulk calculates the total
stock using the quantity and package size. 
# Phase 3

Named parameters make models easier to create and understand because each
argument has a label.
